# /explain

선택한 코드가 무엇을 하는지 설명합니다.

## 설명 포함 항목

1. **목적**: 이 코드가 해결하는 문제
2. **동작 방식**: 단계별 로직 설명
3. **주요 함수/훅**: 사용된 React 훅이나 유틸 설명
4. **데이터 흐름**: props, state, API 호출 흐름
5. **관련 파일**: 이 코드와 연결된 다른 파일들

## 출력 형식

```
## 📌 요약
한 문장으로 요약

## 🔍 상세 설명
단계별 설명

## 🔗 관련 코드
- [파일명] - 연관성 설명
```

## 사용법
코드를 선택한 후:
```
/explain
```
