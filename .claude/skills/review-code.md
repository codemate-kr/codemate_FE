# /review-code

선택한 코드 또는 현재 파일을 리뷰합니다.

## 체크 항목

### 1. 버그 가능성
- null/undefined 체크 누락
- 비동기 에러 핸들링
- 의존성 배열 누락 (useEffect, useMemo)

### 2. 성능
- 불필요한 리렌더링
- 무거운 연산의 메모이제이션 필요 여부
- 큰 컴포넌트 분리 필요 여부

### 3. 타입 안전성
- any 타입 사용
- 타입 단언(as) 남용
- 옵셔널 체이닝 누락

### 4. 코드 스타일
- 300줄 초과 여부
- Import 순서
- 네이밍 컨벤션

## 출력 형식

```
## 발견된 이슈

### 🔴 심각 (버그 가능성)
- [파일:라인] 설명

### 🟡 주의 (개선 권장)
- [파일:라인] 설명

### 🟢 제안 (선택적)
- [파일:라인] 설명
```
